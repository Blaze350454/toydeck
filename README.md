# ToyDeck

A web app that controls several JoyHub-protocol Bluetooth toys at once: intensity sliders with per-motor on/off,
built-in and hand-drawn patterns, live per-toy recordings, and a master STOP.

Open it in Chrome (Android, Windows, Mac, ChromeOS) and choose **Install app** to use it like a normal app.
Settings and recordings stay in your browser. Use **Back up** / **Restore** to move them between devices.
